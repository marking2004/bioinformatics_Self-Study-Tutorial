About this site

本页由高校生物信息学课程任课教师维护，作为课程配套的自学参考资料。 内容面向本科生：用尽量直白的语言和可直接运行的命令 / 代码，把课堂上的知识点拆解成能一步步跟着做的教程。

生信的门槛往往不在算法，而在环境：一台 Linux 服务器、一堆看不懂的命令、动辄几个 G 的文件。 这个站点想做的，就是帮你在正式开工前，把这些"挡路的东西"先理顺。

你可以怎么用

  • 课前预习：按首页的模块列表，先建立整体印象。
  • 动手练习：课后的命令和代码，自己敲一遍比看十遍有用。
  • 课后复习：当作速查手册，忘了就回来翻对应的模块。

内容范围

  • 基础环境：Linux 与命令行、序列比对与 BLAST、RNA-seq 实战
  • 序列与进化：多序列比对与可视化、蛋白质分析 / 设计、系统发育分析
  • 基因组与组学：核酸序列与基因组学、多组学联合分析
  • 实验与应用：分子生物学（引物 / 载体 / CRISPR）、虚拟筛选与药物设计
  • 资源：常用数据库、软件与本地工具推荐

适用对象

生物信息学、生命科学相关专业的本科生；以及任何想自学生信、但被命令行和分析环境劝退的同学。 只要你愿意敲命令，这里的内容都能跟上。

This page is maintained by the instructor of an undergraduate bioinformatics course, as a self-study companion. It is written for undergraduates: lectures are broken into step-by-step tutorials in plain language, with runnable commands and code.

The hard part of bioinformatics is rarely the algorithm — it is the environment: a Linux server, cryptic commands, and multi-gigabyte files. This site aims to clear those obstacles before you start real work.

How to use it

  • Preview: skim the module list on the home page to get the big picture.
  • Practice: type the commands and code yourself — far better than reading ten times.
  • Review: keep it as a quick-reference handbook; revisit a module whenever you forget.

Scope

  • Environment: Linux & CLI, alignment & BLAST, RNA-seq in practice
  • Sequences & evolution: MSA & visualization, protein analysis / design, phylogenetics
  • Genome & omics: nucleic-acid analysis & genomics, multi-omics integration
  • Bench & application: molecular biology (primer / vector / CRISPR), virtual screening & drug design
  • Resources: common databases, software and local-tool recommendations

Who it is for

Undergraduates in bioinformatics and the life sciences, and anyone who wants to learn bioinformatics but is put off by the command line and analysis environment. If you are willing to type commands, you can follow along.
